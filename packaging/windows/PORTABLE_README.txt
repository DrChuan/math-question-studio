高中数学题库：Windows 便携版

双击 MathQuestionManager.exe 即可打开。
当前题库在 data/questions.json，配图在 data/images，新增和修改也保存在这里。

搬到另一台电脑时，请复制整个 MathQuestionManager 文件夹。
不能只复制 exe，也不能删除 _internal、runtime 或 data 文件夹。
无需安装 Python、PySide6 或 LaTeX；运行依赖随文件夹一起提供。
请放在有写入权限的位置，例如桌面或个人文档目录，不要直接在压缩包里运行。

支持 Windows 10/11 64 位（x64）。Windows 11 ARM 可以通过系统的 x64 兼容运行。
程序未做商业代码签名。若系统提示来源未知，请先核实这是你自己打包的文件；不要关闭杀毒软件。

程序使用本机宋体、黑体和 Times New Roman；系统没有相应字体时使用随 LaTeX 提供的替代字体。
Qt、Python 等依赖的许可证保留在 licenses 和各运行目录中，请与程序一起保留。
